🔑 Espace pro

Bienvenue dans ton espace pro Lokalist.

Tout est prêt côté Lokalist. Il te reste une étape pour accéder à ta fiche depuis l'application — ce guide te montre comment, en moins de deux minutes.

Étape 1 · 2 minutes

Activer ton accès

Lokalist t'a transmis un code d'accès par email (du type PRO-AB12). Voici comment l'utiliser.

1

Télécharge l'app Lokalist et connecte-toi

Avec le compte indiqué dans ton email de bienvenue. Si Lokalist t'a créé un compte, utilise l'email et le mot de passe provisoire reçus (tu pourras le changer ensuite).

2

Va dans Profil → « Relier votre espace pro »

Depuis l'onglet Profil, ouvre l'écran de saisie du code.

3

Saisis ton code PRO-AB12

Valide : la section « 🔑 Mon espace pro » apparaît aussitôt dans ton profil. C'est par là que tu accèdes à ta fiche, à tout moment.

💡 Le code est à usage unique et lié à une seule personne. Il n'est à saisir qu'une fois — ensuite, ton espace reste rattaché à ton compte.

Mon équipe

Donner accès à un collaborateur

Ta secrétaire, un associé, un employé peut aussi accéder à l'espace pro — avec son propre compte. Un accès = une personne.

1

Depuis ton espace pro, génère un code d'équipe.

2

Transmets-le à la personne (un code par personne).

3

Elle le saisit dans son profil, au même endroit (« Relier votre espace pro ») — et accède à la fiche.

Besoin de retirer un accès ? Lokalist peut le révoquer à tout moment, sur simple demande.

Questions fréquentes

Les cas qui reviennent

Le code indique qu'il est « déjà utilisé »
Chaque code est à usage unique et pour une seule personne. S'il a déjà servi, demande un nouveau code à Lokalist — c'est immédiat.
J'ai perdu mon code
Aucun souci : contacte Lokalist, on t'en régénère un nouveau et on te le renvoie.
J'avais déjà un compte sur l'app Lokalist
Connecte-toi simplement avec ce compte, puis saisis ton code dans Profil → « Relier votre espace pro ». Pas besoin d'en créer un autre.
Je change de téléphone
Ton espace pro est rattaché à ton compte, pas à ton téléphone. Reconnecte-toi sur le nouvel appareil et tout est là.
J'ai plusieurs établissements
Tu peux relier plusieurs accès : chaque établissement apparaît dans ta section « Mon espace pro ». Demande un code par établissement.
